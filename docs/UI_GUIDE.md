# UI 가이드

## 콘셉트

브랜드명은 **My Shop**. “내일의 일상에 오래 남을 물건”을 선별하는 라이프스타일 숍이다. 포트폴리오에서 흔한 부트스트랩 기본 화면과 구분되도록 따뜻한 아이보리, 잉크색, 코랄 포인트를 사용한다.

## 토큰

- Background: `#F5F1E8`
- Surface: `#FFFDF8`
- Ink: `#1E2723`
- Muted: `#66706A`
- Accent: `#E86542`
- Radius: 카드 20px, 버튼 999px
- Display font: Georgia 계열, Body font: 시스템 sans-serif

## 컴포넌트 원칙

- 버튼은 동사 중심 레이블을 사용한다.
- 상품 카드 전체를 클릭 영역으로 만들되 키보드 포커스를 표시한다.
- 이미지에는 상품을 설명하는 대체 텍스트를 제공한다.
- 768px 이하에서는 내비게이션과 그리드를 단순화한다.
- 애니메이션은 `prefers-reduced-motion`을 존중한다.

## 화면 체크리스트

- 로딩/빈 결과/오류 상태
- 긴 상품명과 큰 가격
- 로그인 전후 내비게이션
- 모바일 360px, 태블릿 768px, 데스크톱 1440px

## 고객 지원 화면

기존 아이보리·잉크·코랄 토큰을 유지한다. 고객에게는 문의와 승인 답변만 표시한다.
관리자에게는 초안 상태, 검토 사유, 수정 가능한 답변, 접을 수 있는 생성 이력을 제공한다.
768px 이하에서는 문의 상세와 정책 폼을 한 열로 배치하고 고객 지원 메뉴를 유지한다.
비어 있는 목록, AI 미연결/실패/처리 중, 입력 오류와 동시 수정 충돌을 별도 안내한다.
초안 생성 상태를 자동 확인하고 새 초안을 별도 영역에서 검토·적용한다. 작성 중인 답변은 자동으로 덮어쓰지 않는다.

관리자 현황 카드와 검색·유형·처리 상태 필터를 제공한다. 작은 화면에서는 카드와 필터를 두 열 또는 한 열로 줄인다. 임시 답변은 복원·삭제를 명시적으로 선택하며, 버전이 다르면 별도 보관본으로 표시한다.
