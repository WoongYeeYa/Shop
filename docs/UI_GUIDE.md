# UI 가이드

## 콘셉트

브랜드명은 **Morrow**. “내일의 일상에 오래 남을 물건”을 선별하는 라이프스타일 숍이다. 포트폴리오에서 흔한 부트스트랩 기본 화면과 구분되도록 따뜻한 아이보리, 잉크색, 코랄 포인트를 사용한다.

## 토큰

- Background: `#F5F1E8`
- Surface: `#FFFDF8`
- Ink: `#1E2723`
- Muted: `#66706A`
- Accent: `#E86542`
- Radius: 카드 20px, 버튼 999px
- Display font: Georgia 계열, Body font: 시스템 sans-serif

## 컴포넌트 원칙

- 버튼은 동사 중심 레이블을 사용한다.
- 상품 카드 전체를 클릭 영역으로 만들되 키보드 포커스를 표시한다.
- 이미지에는 상품을 설명하는 대체 텍스트를 제공한다.
- 768px 이하에서는 내비게이션과 그리드를 단순화한다.
- 애니메이션은 `prefers-reduced-motion`을 존중한다.

## 화면 체크리스트

- 로딩/빈 결과/오류 상태
- 긴 상품명과 큰 가격
- 로그인 전후 내비게이션
- 모바일 360px, 태블릿 768px, 데스크톱 1440px
